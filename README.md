# A1 Studio Website - Local Setup

This folder contains the complete, fully functional local version of the **A1 Studio** website. All styles, scripts, fonts, icons, animations, and image galleries have been updated and verified.

## How to View Locally

### Option 1: Double-Click Launcher (Recommended)
Double-click `start_website.bat` in this folder.
- It will automatically launch a lightweight local server and open `http://localhost:8000` in your default browser.
- Running via a local server ensures all web fonts, animations, and scripts work with 100% fidelity without browser `file://` security restrictions.

### Option 2: Open Directly in Browser
You can directly double-click either:
- `index.html` or
- `Mr.MR.KK Photography.html`

Both point to the fully restored asset structure (`assets/` and `plugins/`).

---

## Directory Structure
- `index.html`: Main website entry point.
- `Mr.MR.KK Photography.html`: Secondary entry point identical to `index.html`.
- `start_website.bat`: One-click local web server launcher.
- `assets/`:
  - `css/`: Full stylesheets (Bootstrap, theme style, header, footer, animations, etc.).
  - `js/`: Core libraries (jQuery, Bootstrap, theme interactions).
  - `img/`: High-resolution photography images, logos, banners, icons.
  - `fonts/`: Bootstrap icons (`.woff2`, `.woff`).
- `plugins/`: Interactive plugins (Swiper slider, WOW scroll animations, Odometer counters, Isotope filtering, Fancybox lightboxes, Flatpickr, etc.).
